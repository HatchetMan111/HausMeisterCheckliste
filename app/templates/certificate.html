Zertifikat auf deinem Gerät bestätigen

Hausmeister läuft mit einem selbstsignierten Zertifikat für {{ app_url }}. Browser akzeptieren dieses Zertifikat nicht automatisch – jedes Gerät muss dem Zertifikat einmalig manuell vertrauen. Ohne diesen Schritt blockiert der Browser u. a. die Offline-Funktionen (Service Worker) und Web Push.

Am einfachsten importierst du die lokale Stammzertifizierungsstelle (Root-CA): Root-CA herunterladen (Datei hausmeister-root-ca.crt).

Der erste Aufruf zeigt eine Browser-Warnung. Über „Erweitert → Weiter zu …“ kannst du die Seite vorübergehend öffnen und dort die CA-Datei herunterladen. Danach folge den Schritten für dein Gerät.

Android (Chrome)

  1. Root-CA herunterladen (Link oben).
  2. Einstellungen → Sicherheit & Datenschutz → Weitere Einstellungen → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat.
  3. Heruntergeladene Datei auswählen und installieren (Geräte-PIN bestätigen).
  4. Chrome vollständig schließen und erneut öffnen, dann {{ app_url }} aufrufen.

iOS / iPadOS (Safari)

  1. Root-CA in Safari herunterladen: es öffnet sich das Profil-Dialogfeld → „Heruntergeladenes Profil installieren“ bestätigen.
  2. Einstellungen → Allgemein → VPN & Device Management → Profil installieren.
  3. Wichtig: Einstellungen → Allgemein → Info → Zertifikatsvertrauenseinstellungen → für „hausmeister … Root-CA“ den Schalter „Volles Vertrauen“ aktivieren.
  4. Safari neu öffnen.

Windows

  1. Root-CA herunterladen.
  2. Doppelklick auf die Datei → „Zertifikat installieren“ → Speicherort „Aktueller Benutzer“ → „Alle Zertifikate in folgendem Speicher speichern“ → „Vertrauenswürdige Stammzertifizierungsstellen“.
  3. Browser neu starten.

Linux (Desktop)

  1. Root-CA herunterladen.
  2. Debian/Ubuntu: Datei nach /usr/local/share/ca-certificates/hausmeister-root-ca.crt kopieren (sudo), dann sudo update-ca-certificates ausführen.
  3. Fedora/RHEL: Datei nach /etc/pki/ca-trust/source/anchors/ kopieren, dann sudo update-ca-trust.
  4. Browser neu starten.

Prüfen, ob alles funktioniert

  1. {{ app_url }} ohne Warnung öffnen.
  2. Auf dieser Seite kein Hinweis mehr: die Offline-Funktionen (Service Worker) sind aktiv.
  3. Push testen: Einstellungen → Web Push → „Push auf diesem Gerät aktivieren“.
